# Services Delta — Safqa API · Contract Templates (change-20260805-171001)

### SVC-CONTRACT-TEMPLATES-01 · ContractTemplatesDataService [domain, internal, Contracts]
- Status: done (delta — content only, no method/schema change)
- `scripts/contract-templates/roya-default.html` redesigned (re-seeded via the existing `scripts/seed-contract-templates.js` upsert — no seed-script logic change):
  - **Cover page** (new, `page-break-after: always`, true edge-to-edge bleed): first page is a single solid `{{brand_secondary}}` fill — no gradient, no swirl/pattern overlay (final design, superseding an initial gradient+swirl draft during live review); large bold hero title + one-line tagline in light text over the solid color; bottom two-column info strip on a light surface background — left: Contract Number / Client Name / Date Issued / Submitted By; right: workspace Phone / Email / Address. Toggled via `body.pdf-cover-pass`/`body.pdf-content-pass` print rules driven by `ContractPdfService`'s two-pass render (see `contracts.md` SVC-CONTRACTS-02 delta) — this is what makes the bleed possible, since Chromium's print-to-PDF always clips content to the page margin box regardless of CSS.
  - **At-a-glance strip** (new): short accent-colored summary band immediately after the cover, before المادة الأولى — Contract Number / Client / Duration / Total (`{{contract_total}}`), using `{{brand_primary}}`/`{{brand_accent}}` for labels.
  - **Watermark** (new): `position: fixed` diagonally-rotated (`-35deg`), low-opacity (`~0.06–0.08`) `{{workspace_name}}` text spanning the content pages (not the cover) — static per Chromium's PDF-repeat behavior for `position: fixed`, no per-page JS required. Page-number visual weight is handled by `ContractPdfService`'s footer template (see `contracts.md` SVC-CONTRACTS-02 delta), not by this template.
  - **Restyle** (existing legal content unchanged in wording/order): numbered clause "badges" (small circular accent-colored numerals) replace plain `المادة X` text headers; boxed callout styling extended to the financial-terms intro and termination clause; refined spacing scale, softer table borders with light `{{brand_surface}}`-tinted header rows, tidier signature block spacing.
  - **Font**: `<head>` now includes `{{document_font_link}}` (Google Fonts `<link>` for the workspace's selected font) and `body { font-family: {{document_font}}; }` replacing the old hardcoded `"Tahoma", "Arial", sans-serif`.
  - The old in-body letterhead block (logo + `<h1>` + contract number/date meta) that used to open page 1 is now folded into the new cover page instead of duplicating there; the article content that follows the cover opens with a slim recap line (contract number/date only) instead of repeating the full letterhead.
- Rendering integration unchanged: `ContractsDataService.renderContractHtml` still takes the resolved template `content` string; new tokens are resolved by that same function (see `contracts.md` delta).
- Admin template editor: any **custom** (non-default) template an admin creates can independently choose whether to use the new tokens — the mechanism (CRUD, default-exclusivity, per-contract override) is unchanged.

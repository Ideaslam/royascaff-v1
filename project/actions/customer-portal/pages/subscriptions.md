## Module: Subscriptions

### Subscriptions & Billing Page
- Route: `/app/subscriptions`
- Components: current Plan+Package version card; separate billing/access and quota-window dates; Package cadence and atomic usage bars; auto-renew; scheduled downgrade/replacement banner; persistent retiring-Plan banner with deadline and replacement CTA; bilingual/RTL active-published Plan cards populated with Package benefits; server preview dialog; immutable invoice history; Pay Now; payment-result toast.
- Service: `getPlans` → `GET /subscriptions/plans`; `getMySubscription` → `GET /subscriptions/me`; `previewChange` → `POST /subscriptions/change/preview`; `upgrade` → `POST /subscriptions/upgrade`; `scheduleDowngrade` → `POST /subscriptions/downgrade`; `cancelDowngrade` → `DELETE /subscriptions/downgrade`; `setAutoRenew` → `PATCH /subscriptions/auto-renew`; `getInvoices` → `GET /subscriptions/me/invoices`; `payInvoice` → `POST /subscriptions/invoices/:invoiceId/pay`.
- Guard: authGuard + onboardingGuard; mutation controls visible only to workspace owner, with backend authorization authoritative.
- States: loading, empty replacement catalog, immutable current version, retirement scheduled/cancelled, notification delivery delayed, replacement pending/failed/paid, grace, scheduled change, and action error/success.
- Notes: no Subscribe Free or destructive cancel. Plan and Package labels resolve in one fixed order *(change-077)* — `plan.displayName` → `plan.name` → `package.name`, using the `*Ar` variant when the active locale is Arabic and its value is non-empty; snapshot readers fall back to `snapshot.name`. Two Plans sharing a Package can therefore render distinct names, and Plans with empty `display*` render exactly as they do today. Usage reset label comes from Package cadence, not Plan billing interval. Upgrade preserves quota; downgrade/same-tier replacement applies at billing end and remains cancellable. Retirement warning remains visible from Plan state even if email fails. Never render provider tokens/raw gateway data.
